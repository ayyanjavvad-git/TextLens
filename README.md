# **TextLens — Text Analyzer**



TextLens is a web application built with Python and Flask that analyzes text and displays useful statistics.



## **Features**



- Count the number of words



- Count the number of characters



- Estimate the number of sentences



- Display the five most common words



- Provide writing recommendation based on text size



## **Technologies Used**



- Python



- Flask



- HTML



- CSS

## **How to Run Locally**

- Clone this repository.



- Open a terminal in the project folder.



- Create a virtual environment:



- py -m venv venv



- Activate the virtual environment on Windows:



- venv\\Scripts\\activate



- Install the dependencies:



- py -m pip install -r requirements.txt



- Start the application:


- py app.py



Open http://127.0.0.1:5000 in your browser.
